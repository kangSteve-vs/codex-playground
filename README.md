# 康康的小站

这是康康的第一个个人网站，也用来练习 GitHub 和 Codex。页面采用简洁的浅色和绿色风格，支持电脑与手机屏幕。目前我还是计算机小白，喜欢使唤 AI；别的小项目以后会慢慢加入。

## 仓库里有什么？

仓库可以理解为“项目文件夹 + 修改记录”。这个网站只需要两个页面文件：

| 文件 | 作用 | 可以尝试修改什么 |
| --- | --- | --- |
| `index.html` | 网页的内容和结构 | 标题、自我介绍、兴趣、链接 |
| `style.css` | 网页的外观 | 颜色、字号、间距、布局 |
| `README.md` | 在 GitHub 上展示的项目说明 | 记录项目用途和使用方法 |

这是静态网站：浏览器直接读取 HTML 和 CSS，不需要数据库、安装依赖或执行构建。插图也包含在 HTML 中，没有外部字体或图片依赖。

## 怎样查看页面？

下载仓库文件到自己的电脑后，双击 `index.html` 即可用浏览器查看。请把 `style.css` 留在同一个文件夹中。

在有 Python 3 的开发环境里，也可以进入仓库目录运行：

```bash
cd /workspace/codex-playground
python3 -m http.server 8000 --bind 127.0.0.1
```

这会启动仅供当前机器检查页面的服务器，按 `Ctrl+C` 停止。在 Codex 云环境中，这不是对外发布的网址；可以让 Codex 使用本地请求和浏览器检查页面。

## 怎样让别人访问？

可以使用 GitHub Pages 托管这个网站，无需购买服务器或域名。以下步骤尚需在 GitHub 完成；创建文件并不代表网站已经上线。

1. 将网站文件提交并推送到 GitHub 仓库的 `main` 分支。如果修改在其他分支，先创建 PR（合并请求），检查后合并到 `main`。
2. 打开 GitHub 仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中，把 **Source** 设为 **Deploy from a branch**。
4. 选择 **main** 分支和 **/ (root)** 目录，然后保存。
5. 等待部署完成，以 Pages 设置中显示的访问地址为准。按当前账号和仓库名，预期地址是 `https://kangSteve-vs.github.io/codex-playground/`。

GitHub Free 支持公开仓库的 Pages；私有仓库的可用性取决于账号套餐。如果没有 Pages 选项，先检查仓库可见性、权限与套餐，不要为了发布直接公开含私人内容的仓库。

此后更新 `main` 上的网站文件，GitHub Pages 会自动重新部署。

## 第一次练习

1. 在 `index.html` 中找到“欢迎来到”，修改首页标题或介绍。
2. 在 `style.css` 开头找到 `--green`，尝试改变绿色主题色。
3. 查看页面效果和代码差异，把满意的修改保存为一次 **Commit（提交）**，例如“更新个人介绍”。

**分支**用来单独开展一项修改；**提交**记录一个版本；**推送**把本地提交上传到 GitHub；**PR**用于检查并合并分支上的修改。发布网站是另一个步骤，GitHub 上有代码不等于已经开启 Pages。
